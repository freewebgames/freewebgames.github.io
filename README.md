# freewebgames.github.io
Homepage for freewebgames. Also contains some other games that dont require multiple assets.

## Contributing?
Thank you for wanting to contribute. If you do the steps below, there is a high probability that I will add your game! (It has to be single file.)
1. Make a pull request with the file in the folder HTML or Flash (depending on type)
2. Place an image in the Assets folder (if you can find one!)
3. Add a config.txt entry in the correct format.
