# freewebgames.github.io
Homepage for freewebgames. Also contains some other games that dont require multiple assets.

## Want to contribute a single-file game?
Thank you for wanting to contribute. To get your pull request accepted, please follow these steps:
1. Place the file in the HTML or Flash folder, depending on type.
2. Place an image in the Assets folder if you can find one.
3. Add a config.txt entry for your game in the correct format. (see the other entries)
